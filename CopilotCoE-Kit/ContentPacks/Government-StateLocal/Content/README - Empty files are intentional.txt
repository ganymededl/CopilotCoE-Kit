EMPTY FILES IN THIS FOLDER ARE INTENTIONAL

These three files are 0 bytes on purpose. The kit removes a page or document when the
organization folder has an empty file at the same path, and the file name must match the kit's
original name, so the higher-ed names stay:
  Guides\02-Students-and-AI.md                 -> Students and AI guide is not published
  Guides\03-Teaching-and-Learning.md           -> Teaching and learning guide is not published
  Higher-Ed-AI-Governance-Framework-DRAFT.md   -> higher-ed overarching policy draft is not published

Do not delete them: without them the kit publishes its higher-ed versions.
All other files here are government content (governance drafts are in Governance\leadership\
and Governance\program\<folder>\Sample-guidance.txt). Files named README* are not uploaded.
