# Using and building agents

> What agents are, which ones to use, and your organization's rules for building and sharing them.

An agent is Copilot set up for a particular job. Some are built by Microsoft, such as **Study and Learn**, or **Researcher** and **Analyst**, which need a paid Copilot license. Others can be built by staff in your organization, for example an agent that answers questions from a department's published procedures.

## Using agents

- Use agents published by Microsoft or listed by your organization in the Copilot agent store.
- Check who owns an agent before relying on it. An agent's answers are only as good as its sources.
- Apply the same data rules as any Copilot prompt.

## Building agents: proposed organizational rules

1. **Low risk, allowed after training:** personal or team agents that use only public or non-sensitive internal sources you already own, shared with your own team.
2. **Needs CoE review before sharing:** agents shared beyond a team, agents used by students, or agents that use a SharePoint site with mixed content.
3. **Needs formal approval:** agents that use or could reach student records, personnel data, financial aid, health, or other restricted information, or that take actions in other systems.
4. **Not permitted:** agents that profile, rank, or monitor students or employees, or that make consequential decisions about people.

Every shared agent must have a named owner and a backup. Agents without an active owner are reviewed and may be turned off.

## Lifecycle

- Register the agent, its purpose, sources, audience, and owner with the CoE.
- Review shared agents at least each semester and when sources or audience change.
- Retire agents that are no longer used or maintained.
