# Agent Showcase
> Find an approved agent, check its sources and access requirements, then open it in Copilot Chat.

## Find an agent for your task

Listing an agent does not give you access to it or its sources, or approve any charges.

Select an agent's link to open it in Microsoft Copilot Chat. Sign in with your work or school account. If it is unavailable, check its access requirements and use the listed support route, if provided; access, licensing or configuration may need attention.

## Before you open an agent

Select the agent's name to see its sources, example prompt, access and billing requirements, allowed data, owner, support contact and review dates. Confirm it fits your task before opening it.

## Share an agent you built

1. **Prepare a proposal first.** Describe the task, audience, owner/backup, knowledge sources, connectors/actions and a suitable example prompt. Do not put confidential records, credentials or investigation details in the catalog.
2. **Check the data.** The agent may use only sources its users are allowed to see. Agents that use confidential or regulated data must go through the CoE review in the Copilot operations guide first.
3. **Send the proposal through [Service Catalog and Support](CoE-Service-Catalog-and-Support.aspx)** or add a submission to the list if you have contribution access. The CoE reviewer checks the listing and [lifecycle requirements](Agent-Lifecycle-and-Approval.aspx).
4. **Wait for any required IT admin-center approval** before wider sharing. Showcase content approval makes a listing visible, but is not itself authorization to deploy or share the agent.
5. **Share the agent only with the approved audience**, and only after the required reviews. Don't invite the wider community to test an unapproved agent.

Changes to a listed agent are reviewed before they appear. Contact the CoE team if an agent needs correcting or should be removed.
