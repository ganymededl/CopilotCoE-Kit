ROADMAP DECKS - HOW TO USE THIS FOLDER

Post Microsoft 365 Copilot roadmap decks here as they become available, then
announce each one in the Feedback and Roadmap channel.

1. Name files with the date first: YYYY-MM-DD_<Source>_Copilot-Roadmap.pptx
   Example: 2026-10-15_Microsoft_Copilot-Roadmap.pptx
2. Post only decks approved for everyone in this Team. Decks shared under a
   nondisclosure agreement belong in the restricted Leadership Governance channel.
3. Move decks older than two quarters to an Archive subfolder so the newest
   briefing is always on top.

Public sources that stay current between briefings:
  https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes
  https://www.microsoft.com/en-us/microsoft-365/roadmap?filters=Microsoft%20Copilot
