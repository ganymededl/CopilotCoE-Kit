# Which Copilot should I use?
> Choose an approved experience based on the task, your data and your organization's access rules.

| If you want to... | Start with... |
|---|---|
| Draft or explore ideas with information you provide | Copilot Chat with your work or school account, if enabled |
| Work with email, meetings and files you can access | Microsoft 365 Copilot, if your organization assigned the product license |
| Research a complex question or analyze data | Researcher or Analyst, if available to you in the Microsoft Copilot app |
| Build an agent for an approved audience | Where agents are built, then Agent lifecycle and approval |

Use [Compare all tools](Compare-Copilot-Tools.aspx) for the full comparison and cloud caveats. The Microsoft Copilot app is an interface; Microsoft 365 Copilot remains the paid product and license name. Check your organization's data rules before adding non-public information.
