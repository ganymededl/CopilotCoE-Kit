# Where agents are built
> Start with a supported surface, but confirm your tenant, cloud, licensing, data rules and approval path before creating or sharing.

| Surface | Use it for | Check before using |
|---|---|---|
| Microsoft 365 Copilot agent builder | Narrow assistants for permitted tasks and work information | Microsoft 365 Copilot entitlements, sharing limits, allowed knowledge and admin policies |
| SharePoint agents | Assistants grounded in approved site or library content | The actual source permissions, agent access and tenant capacity |
| Copilot Studio | Low-code agents with approved knowledge and actions | Environment, DLP, connectors, billing and cloud feature differences |
| Microsoft Foundry | Pro-code Azure AI applications and agents, where enabled | Azure cloud and portal, Azure resource permissions and separate security approval |

[Compare the tools](Compare-Copilot-Tools.aspx) to confirm licensing and availability for your tenant before building.

After choosing a surface, follow [Agent lifecycle and approval](Agent-Lifecycle-and-Approval.aspx). A maker's successful build or Showcase listing is not IT admin-center approval.

Learn more: [Microsoft 365 agent builder](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/copilot-studio-agent-builder), [SharePoint agents](https://support.microsoft.com/en-us/sharepoint/copilot-in-sharepoint/get-started-with-agents-in-sharepoint), and [What is Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/fundamentals-what-is-copilot-studio).
