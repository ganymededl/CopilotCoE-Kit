01 Admin Quickstart: Copilot CoE install

Run these steps one at a time from PowerShell 7. Keep the organization folder outside the kit so future kit updates do not overwrite customer settings.

Critical: Do not use -ResumeExisting for a clean build. Configure Links.DataSafetyIncident as an approved HTTPS incident route before install, or the installer stops before creating tenant resources.

01Extract the kit and create the organization folder

Pick the starting folder for the customer's environment. It decides the site's wording, governance drafts, learning paths and the base prompts in the Copilot Prompt Library. If you were given a completed organization folder, copy that folder instead.

CustomerCopy this folderBase prompts
Higher educationOrg-Template230 higher-ed prompts (kit default)
State and local government (commercial or GCC-Moderate; not GCC High or DoD)ContentPacks\Government-StateLocal230 general government prompts; higher-ed prompts left out
$installRoot = 'C:\CoE-Install\Contoso'
$kitRoot = Join-Path $installRoot '03_Build\CopilotCoE-Kit'
$orgPath = 'C:\CoE-Orgs\Contoso'

Set-Location $kitRoot
# Higher education:
Copy-Item .\Org-Template $orgPath -Recurse -Force
# Government (use this line instead of the one above):
# Copy-Item .\ContentPacks\Government-StateLocal $orgPath -Recurse -Force
notepad (Join-Path $orgPath 'Deployment-Settings.json')
  • Set tenant fields, owner UPN, organization name, support mailbox and email domains.
  • Keep TeamVisibility as Private.
  • Fill Links.ServiceDesk, TechnologyRequest, AIGuidelines and DataSafetyIncident with real HTTPS routes.
  • Government only: replace every <placeholder> and set TimeZone (for example Central Standard Time).

Optional: the organization's own prompts

The Copilot Prompt Library starts with the base prompts above. To add the customer's own prompts, put CSV files in $orgPath\Content\OrgPrompts in the Microsoft 365 admin center import format (Title,Description,Display Prompt,Prompt Text,Products,Department,Task Type,Locale) — the same files you would upload in Copilot > Prompts > Import. A new file name adds prompts; a base file's name replaces that file; an empty file with a base file's name leaves it out. The kit does not change the files. To leave the list out, set "PromptLibrary": "Off".

02Register or update the provisioning app

An approved consent approver runs this once per tenant, then confirms all required permissions show Granted in Entra.

Set-Location $kitRoot
Install-Module PnP.PowerShell -RequiredVersion 3.2.0 -Scope CurrentUser
.\01_Register-CoEProvisioningApp.ps1 -OrgPath $orgPath
Check before continuing: Entra app permissions must be granted, including delegated User.Read.All. If consent changes after a previous sign-in, add -ForceAuthentication to the install command below.

03Run the clean install

The SharePoint + Teams administrator runs this after settings and app consent are ready.

Set-Location $kitRoot
.\02_Install-CopilotCoE.ps1 `
  -OrgPath $orgPath `
  -SeedDemoContent `
  -AcceptOrgAssets

A first install takes about 25–35 minutes; adding the 230 base prompts accounts for 5–10 of them.

Clean install only: Do not add -ResumeExisting. If sign-in needs refreshing, rerun the same command with -ForceAuthentication.
If it stops with an error: do not retry with -ResumeExisting and do not edit files. Every run saves a log to $orgPath\RevisionAudit\*-transcript.txt. Send that file to your Microsoft contact. A site that stopped partway is removed with 04_Remove-CopilotCoE.ps1 -Purge and rebuilt from the start.

04Check the result - the install is not finished until this passes

This reads the site and changes nothing. Use the site address printed at the end of step 03.

$siteUrl = 'https://contoso.sharepoint.com/sites/CopilotCoE'

Set-Location $kitRoot
.\Test-CoEInstall.ps1 -OrgPath $orgPath -SiteUrl $siteUrl
Done means: the last line reads ALL CHECKS PASSED. Any FAIL line names what is wrong; send that output together with the run log.

05Before readers see it

  • Add at least one non-owner member/reader test account before acceptance testing.
  • Approve and feature one Agent Showcase entry to test both empty and populated reader layouts.
  • Open Prompts in the site menu and check the Organization prompt library shows your environment's prompts (government sites must not show higher-ed prompts).
  • To add or remove a catalog reviewer, edit the CoE Catalog Reviewers group in SharePoint; no script rerun is needed.
  • Use .\03_Update-CoEContent.ps1 -OrgPath $orgPath -Scope All only for reviewed updates, then run step 04 again.
